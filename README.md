# 🤖 المعاون — مساعد شخصي بالصوت، بالاشتراك

تطبيق Android: تضغط 🎙️، تحكي بالتونسي عادي، والـagent يتصرّف — روزنامة،
تذكيرات، رقيمات، رسائل، نوتات، بحث في الويب.

> «ذكّرني غدوة مع 10 نكلم محمد» · «شنوة عندي اليوم؟» · «ابعث لسامي رسالة
> قولّو إنو وصلت» · «اعمل note: لازم نشري 20 carton»

وراه منصّة كاملة: **أنت** عندك الـAPI key، **الناس** يخلّصو اشتراك شهري،
و**اللوحة** تورّيك شكون يستعمل شنوّة وقدّاش يكلّفك.

---

## البنية

```
📱 Android (Kotlin + Compose)          ← الميكرو، الروزنامة، الرقيمات، SMS
      │ jeton Google (Supabase Auth)
      ▼
⚡ Edge Function  agent                 ← المفتاح متاع الـAI يقعد هوني برك
      │  1. عندو اشتراك؟ كريدي؟ ما فاتش سقف النهار؟
      │  2. أنهي apps مسموحة (الـadmin ∩ المستخدم ∩ الاشتراك)
      │  3. ينادي الموديل ويدير الـtools
      │  4. يسجّل tokens + الكلفة الحقيقية
      ▼
🐘 Postgres + RLS  ──────────────────►  🖥️ لوحة الـAdmin (Lovable)
   users · plans · credits · tools         الاستهلاك، المداخيل، الـapps
   usage_events · app_sessions
```

| القطعة | فين | الحالة |
|---|---|---|
| قاعدة المعطيات + RLS + الـviews | `supabase/migrations/` | ✅ مجرّبة على PostgreSQL حقيقي |
| الـagent، الخلاص، الـwebhooks | `supabase/functions/` | ✅ 26 test |
| تطبيق Android | `android/` | ✅ يكومبيلي ويطلع APK |
| apps متاع Google (Agenda، Drive، Gmail) | `_shared/google.ts` | ✅ 11 test — يلزمها Google Cloud |
| لوحة الـAdmin | Lovable | 📋 [الـprompt والـqueries](docs/ADMIN-DASHBOARD.md) |

## القواعد اللي بنينا عليها

**المفتاح متاعك ما يخرجش.** التطبيق ما يشوف حتى مفتاح متاع AI. كل نداء يعدّي
من Edge Function، وثمّة اللي يتحسب الاشتراك والكريدي.

**الكريدي يتحسب قبل ما ينفق.** طلب واحد = كريدي واحد، يتنقّص في نفس الـ
transaction اللي تتثبّت في الاشتراك — يعني ما ينجّمش واحد يعمل spam. وكان
الفورنيسور طاح، الكريدي يرجعلو.

**الخلاص ما يتصدّقش من الـclient.** الثمن ديما من قاعدة المعطيات. الـwebhook
متاع Flouci ما نصدّقوهش — نسألو Flouci direct. Stripe نتثبّتو من الـsignature.
والـwebhook اللي يتعاود ما يعطيش كريدي مرّتين.

**الـagent ما يبعثش وحدو.** الرسائل والمكالمات: التطبيق يحلّ تطبيق الرسائل
ولا الclavier بالنص محضّر، والمستخدم هو اللي يضغط. (وهكا زادة ما نحتاجوش
أذونات SMS اللي Google Play تمنعها.)

**المستخدم يحكم في الـapps متاعو.** الـadmin يشعّل app للجميع، وكل واحد
يقبل ولا يرفض وحدة وحدة، وينجّم يطفّيها وقت ما يحب. والـagent ما يشوف كان
اللي تسمّح بيه.

**المحادثات محرّمة عليك.** الـRLS ما تخلّي حتى الـadmin يقرا رسائل الناس.
تشوف الأرقام برك: tokens، كلفة، وقت.

**الموديل مفصول.** `LlmProvider` interface وحدة، وأداپتور Claude وراها.
تبدّل الفورنيسور = ملف جديد + سرّ `AI_PROVIDER`، والمحادثات القديمة تبقى
تتقرا (نخزنو في format محايد).

## الاشتراكات

3 formules (`plans`) تبدّلهم من اللوحة بلا نشر جديد:

| | أساسي | برو | ماكس |
|---|---|---|---|
| في الشهر | 15 د.ت / 9 $ | 30 د.ت / 19 $ | 60 د.ت / 39 $ |
| طلبات | 500 | 1500 | 5000 |
| سقف النهار | 60 | 150 | 400 |
| الموديل | standard | advanced | advanced |

الخلاص: **Flouci** بالدينار، **Stripe** بالـcarte، ولا **يدوي** (رقم واحد في
SQL) لواحد خلّص cash.
